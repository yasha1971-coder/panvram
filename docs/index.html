How it works

Each assembly is stored as a refrel3 archive: blocks coded against a shared reference, with a table that maps any coordinate to its block. The whole cohort is loaded into GPU memory once; after that a query never touches disk.

Input
558 HPRC assemblies
Encode
refrel3 v1 archives
Resident
16.6 GB on one GPU
Query
(genome, contig, start, len)
Answer
exact source bases

Coordinates are 0-based, end-exclusive, within one contig. The answer is the source bases with case and IUPAC codes preserved, without headers or line breaks.

Reproduce it

The public notebook runs the full 558/558 gate from the published dataset. No account or token needed.

  1. Open the notebook on Colab with a GPU runtime: quickstart_558.ipynb
  2. It downloads the 500 MiB dataset parts from Zenodo and checks each SHA-256.
  3. It loads all 558 archives on the GPU, samples random windows, and decodes every assembly in full, checking each against the manifest.

Local install and the CPU-only quick start are in the README.

Found a mismatch or a failed run? Please open an issue with the log and your hardware details.
